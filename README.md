# بوابة التواصل المؤسسي

منصة التواصل المؤسسي لشركة الأندلس التعليمية. النسخة الجاهزة للنشر في `docs/`.

## النشر على GitHub Pages
1. أنشئ مستودعاً (يُفضَّل **خاصاً** — راجع الأمان أدناه) وارفع محتويات هذا المجلد.
2. Settings → Pages → Source: **GitHub Actions**.
3. أي دفع إلى `main` يغيّر `docs/` ينشر الموقع تلقائياً (`.github/workflows/pages.yml`).

> المستودع الخاص مع Pages يتطلب خطة GitHub تدعمه (Pro/Team/Enterprise). على الخطة المجانية يلزم مستودع عام.

## الأمان
- الأقسام المحمية (الأداء والتطوير، دراسة المنافسين) مشفّرة AES-GCM داخل `public-data.json`، وتُفك في المتصفح بكلمة المرور فقط. في مستودع عام يستطيع أي شخص تنزيل الملف المشفّر ومحاولة تخمين كلمة المرور، فاستخدم كلمة مرور طويلة وفريدة.
- مفتاح التشفير غير موجود في المستودع. لا تضفه.

## تحديث البيانات
- الموقع قراءة فقط: لا تعديل حي من الصفحة (لا توجد قاعدة بيانات).
- لتحديث البيانات: أنشئ نسخة جديدة من `docs/public-data.json` (`tools/make_public_data.py`) وادفعها.
- التحديث اليومي من Google Sheets **غير مفعّل بعد في GitHub**؛ ما زال يعمل عبر مهمة Claude المجدولة على المنصة الحالية. نقله يحتاج إعداد GitHub Actions أو مهمة Claude Code مع صلاحية دفع وأسرار المفتاح، ويُنفَّذ كخطوة منفصلة.
- المحتوى المفتوح (الفيديو، الملفات، الروابط السريعة، الفعاليات) يُعدَّل داخل `public-data.json` (مجموعات files, settings, events…).

## العمل مع Claude Code
افتح المجلد في Claude Code؛ سيقرأ `CLAUDE.md` تلقائياً.
